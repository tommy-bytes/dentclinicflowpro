# DentClinicFlow Pro — pagini legale

Sursa site-ului publicat prin GitHub Pages pentru aplicația **DentClinicFlow Pro**
(programări, program de lucru și pontaj pentru clinici stomatologice, pe macOS,
iPadOS și iOS).

| Pagină | Folosită în App Store Connect ca |
|---|---|
| `privacy.html` | Privacy Policy URL |
| `terms.html` | License Agreement / EULA — link obligatoriu în descriere (regula 3.1.2) |
| `support.html` | Support URL |
| `privacy-en.html` | politica în engleză, pentru magazinele non-RO |

Site static, fără JavaScript, fără cookie-uri, fără urmărire.

## Producător

Paginile identifică producătorul ca **MSCS di Stefan E.**, cu
stefan@support-remote.org drept contact — la fel ca celelalte aplicații. Dacă
adresa înregistrată trebuie să apară, se adaugă un rând `<dt>` în blocul de
contact din `privacy.html`, `privacy-en.html` și `terms.html`.

## Ce nu se pune aici

Niciun nume de pacient, niciun date de clinică, niciun identificator. Repozitoriul
este public.
